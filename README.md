# Hey, I'm Rajnish 👋

I'm a Security Engineer, passionate about understanding how systems work, exploring their security boundaries, and building software to make them more secure.

I enjoy working at the intersection of **security research, systems programming, and defensive engineering**. Whether it's investigating low-level system behavior, designing authentication infrastructure, or building security tooling, I'm most interested in problems that require both deep technical exploration and practical engineering.

### 🔧 What I work on

- **Security Engineering:** Building defensive security tools, security infrastructure, and automation.
- **Systems & Authentication:** Linux security, SSH, PKI, hardware-backed cryptography, and identity systems.
- **Software Engineering:** Developing tools and services using Rust, Go, and Python.
- **Security Research:** Exploring vulnerabilities, reverse engineering, and understanding security boundaries.
- **Infrastructure & Networking:** Secure systems, network protocols, monitoring, and performance engineering.
